사용 안내

ssalmuck-ai는 Google Gemma 4 31B 모델을 OpenAI와 같은 방식으로 부르는 API입니다. OpenAI 호환 API를 지원하는 앱에 주소, 키, 모델 이름을 넣으면 바로 쓸 수 있습니다.

처음 쓰기

  1. 키를 받습니다.

    키 페이지에서 구글로 한 번 확인하고 패스키를 만들면 키가 나옵니다. 키 없이도 쓸 수 있지만 한도가 작습니다.

  2. OpenAI 호환 API를 지원하는 앱을 엽니다.

    Chatbox, RisuAI 같은 앱입니다.

  3. 앱의 설정에 세 값을 넣습니다.

    API 주소
    https://ssalmuck-ai.duckdns.org/v1
    API 키
    받은 키. 키 없이 쓰면 비워 둡니다.
    모델
    gemma-4-31b-it

  4. 짧은 메시지를 보내 봅니다. 답이 오면 설정이 끝난 것입니다.

앱이 키 칸을 비워 둘 수 없게 하면 키를 받아서 넣습니다. 아무 글이나 넣으면 등록되지 않은 키라서 401 오류가 납니다.

브라우저 앱

웹 브라우저 안에서 도는 앱은 키가 있어야 합니다. 다른 웹사이트에서 이 API를 부를 때는 키가 있는 요청만 허용하고, 키 없는 요청은 브라우저가 막습니다.

등급과 한도

공개한 기본값입니다.

등급시간당하루
키125만 토큰4,000만 토큰
검증 IP75만 토큰1,500만 토큰
미검증 IP30만 토큰750만 토큰

키가 있으면 키로, 없으면 IP 주소로 사용자를 구분합니다. IPv6는 /64 단위입니다. 검증 IP는 한국 가정용·모바일 회선에서 요청이 과하지 않은 IP입니다. 미검증 IP는 해외, 데이터센터·호스팅 대역, 조건을 어긴 IP입니다.

한도는 지난 60분과 지난 24시간을 1분 단위로 셉니다.

시간당 한도를 넘은 요청도 받지만 처리 순서가 크게 밀립니다. 하루 한도를 넘으면 429 오류가 납니다. 키 없는 요청 전체에도 하루 한도가 있습니다.

처리 순서는 키, 검증 IP, 미검증 IP 순입니다. 같은 등급에서는 한도 안의 요청이 먼저입니다.

검증 IP의 판정 기준은 공개하지 않습니다. 국가와 대역은 서버 안의 DB-IP Lite로 판별합니다. IP 위치 정보: db-ip.com, CC BY 4.0.

한도에서 빼는 양

요청마다 아래 셋을 더한 만큼 한도에서 뺍니다. 모든 등급이 같습니다.

토큰배수
캐시되지 않은 입력1
출력. 생각도 출력입니다.5
캐시된 입력0.1

입력 2,000토큰에 출력 500토큰이면 4,500을 뺍니다.

동시 요청

한 사용자가 한꺼번에 보낸 요청은 뒤의 것일수록 처리 순서가 밀립니다.

진행 중인 요청처리 순서
첫 1개우선
다음 3개보통
다음 8개낮음
13번째부터받지 않음. 429 오류

지원 값

요청에 넣을 수 있는 값입니다. 앱의 설정 화면에 같은 이름으로 있는 경우가 많습니다.

값기본값과 뜻
temperature기본 1.0. 높을수록 답이 다양해집니다. 0이면 늘 가장 가능성이 높은 토큰을 고릅니다.
top_p기본 0.95. 가능성이 높은 토큰부터 더해 이 비율 안에 드는 것 중에서 고릅니다.
top_k기본 64. 가능성이 높은 토큰 몇 개 중에서 고를지 정합니다. 1,024까지입니다.
seed토큰을 고르는 난수의 시작값입니다.
max_tokens기본 8,192. 답의 최대 길이입니다. 더 크게 주면 8,192로 줄입니다. max_completion_tokens도 같습니다.
stop이 글이 나오면 답을 멈춥니다. 글 하나 또는 목록입니다.
stream기본 false. true면 답을 쓰는 대로 조금씩 보냅니다.
tools모델이 부를 수 있는 함수 목록입니다.
thinking기본은 끔. 켜면 생각한 뒤 답합니다.

입력은 32,768토큰까지입니다. 더 길면 400 오류가 납니다.

받지만 쓰지 않는 값

presence_penalty, frequency_penalty, repetition_penalty, min_p, logit_bias. 요청은 그대로 처리하고, 응답의 x-sclmd-ignored 머리글에 쓰지 않은 값의 이름을 적습니다.

거절하는 값

1이 아닌 n, logprobs, top_logprobs, strict json_schema. 이 값이 있으면 400 오류가 납니다.

자주 나는 오류

코드뜻과 할 일
401키가 틀렸거나 회수된 키입니다. 키를 다시 붙여 넣습니다. 키 없이 쓰려면 키 칸을 비웁니다.
429하루 한도를 넘었거나 동시 요청이 너무 많습니다. 응답의 Retry-After에 적힌 초만큼 기다립니다. 하루 한도라면 몇 시간일 수 있습니다.
502서버가 꺼져 있습니다. 나중에 다시 합니다. 지금 상태는 홈에 있습니다.
503서버가 다시 시작하는 중입니다. 잠시 후 다시 합니다.
400입력이 너무 길거나 거절하는 값이 있습니다. 대화를 줄이거나 그 값을 뺍니다.
